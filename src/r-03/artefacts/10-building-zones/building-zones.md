# Зоны сортировочного центра: назначение, площади, компоненты

**Задача:** `src\r-03\prompts\10-building-zones.txt`
**Основание:** `src\specs\specification-r-01.md` (v2.0), `src\specs\Robozone Task 1.txt`, артефакты этапов 1–4.
**Выход:** перечень зон СЦ с назначением, оценочными площадями, статическими и динамическими компонентами, взаимным расположением.

Правила учета:
- площади — из оценочной таблицы спецификации 5.2 (диапазоны);
- размеры/компоновка зон не рассчитываются (этапы 6–7);
- терминология по глоссарию спецификации.

---

## Общая схема расположения зон (спецификация 5.1)

Основной поток слева направо: **въезд → приёмка → разукрупнение → вскрытие → подача (инфиды) → сортировка → заклейка → сортировка ящиков по направлениям → паллетирование → отгрузка → выезд**.

Боковые зоны: сток пустых ящиков (+ машина новых ящиков), nonsort (адресные ячейки + роллтейнеры), возвратные каналы, брак ящиков + вывоз отходов, инфраструктура.

## 16. Противоречия и неточности (сверка с ТЗ и спецификацией)

1. Площади зон в ТЗ отсутствуют — в спецификации даны оценочные диапазоны (раздел 5.2); противоречий значений нет.
2. Сток пустых ящиков (зона 4) по спецификации 7.3 должен располагаться «рядом с зоной загрузки сортировщика»; точное положение определяется компоновкой (этап 6–7).
3. Буферы приёмки (≈400 паллетомест) и отгрузки (≈370 паллетомест) заданы как оценочные в спецификации 5.2/3.3 — не противоречат ТЗ.
4. Противоречий между зонами спецификации и ТЗ не выявлено; новые неточности внесены в `src\r-03\contradictions-report.md` (при необходимости).
