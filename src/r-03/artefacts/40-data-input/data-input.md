# Входные данные для аналитической модели

**Задача:** `src\r-03\prompts\40-data-input.txt`
**Основание:** `src\specs\specification-r-01.md` (v2.0 — новейшая спецификация) и `src\specs\Robozone Task 1.txt`.
**Выход:** перечень входных данных для аналитической модели — только значения, явно заданные в ТЗ или спецификации, с указанием источника.

Обозначения статуса:
- **задано** — значение явно указано в ТЗ или спецификации;
- **ориентир** — значение указано в спецификации как проектная оценка/допущение (раздел 3.4 или таблицы оборудования/площадей);
- **не задано** — значение отсутствует, подлежит расчёту или калибровке на последующих этапах.

Терминология по глоссарию спецификации: **ящик**, **паллета**, **роллтейнер**, **робот-перевозчик**.

## 7. Недостающие параметры (для расчёта/калибровки)

5. Распределение по направлениям (Парето 80/20, степень концентрации) — п. 1.10.
6. Скорости конвейеров, такты ячеек, ёмкости скатов/стока/накопителей — п. 3.20.
7. Размеры роллтейнеров — п. 2.11.
8. Парк роботов-перевозчиков и погрузчиков — п. 3.18, 3.19.
9. График магистрального транспорта (прибытие/отправление, волны) — п. 6.6, 6.7.
10. Финальные площади участков (компоновка) — п. 4.1–4.15.

Эти параметры будут определены балансовыми расчётами и калибровкой имитационной модели на последующих этапах (критерии: «очереди → 0», «время в СЦ → min»).
