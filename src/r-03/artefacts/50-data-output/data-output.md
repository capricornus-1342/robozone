**Задача:** `src\r-03\prompts\50-data-output.txt`
**Основание:** `src\specs\specification-r-01.md` (v2.0 — новейшая спецификация) и `src\specs\Robozone Task 1.txt`.
**Выход:** перечень метрик для оценки работоспособности схемы СЦ, сравнения вариантов и калибровки имитационной модели.

Правила учета:
- указывается только перечень метрик (значения не вычисляются);
- для каждой метрики: название, единица, способ получения, источник в спецификации;
- терминология по глоссарию спецификации.

## 9. KPI для сравнения вариантов

На основе метрик определён минимальный набор KPI для сравнения вариантов организации СЦ:

1. **Пропускная способность системы** — достигает ли 100 000 товаров/ч на входе и выходе (метрика 1.1, 1.6).
2. **Узкие места** — участки с загрузкой > 90 % (метрики 2.1–2.2, 1.5): по спецификации 11.1 это сортировка/инфид (100 %) и ворота отгрузки (96,4 %).
3. **Dwell time** — среднее время в СЦ, минимизируется (метрики 4.1–4.2).
4. **Потребность в людях и оборудовании** — сравнение вариантов автоматизации (метрики 7.1–7.2).
5. **Устойчивость** — деградация при отказах и время восстановления (метрики 8.1–8.4).
