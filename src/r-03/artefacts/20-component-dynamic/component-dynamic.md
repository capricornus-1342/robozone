## 2. Потоки движения динамических компонентов

### 2.1. Основной поток товаров (главный, центральный)

**Траектория** (спецификация 6.1, с уточнением): ворота приёмки → буфер приёмки → депаллетизация → вскрытие ящиков → инфид (сканер, весы, габариты) → сортировщик → сброс на скаты → этап заполнения ящиков (скаты/накопители после сортировки; установка пустых ящиков, утряска, съём) → линия заклейки → сортировка ящиков по направлениям → паллетирование → буфер отгрузки → ворота отгрузки → машина.

**Способ транспортировки:** конвейеры (ящики между участками вскрытия/подачи), технические средства зон (товары на инфиды и сортировщик), роботы-перевозчики/погрузчики (паллеты, роллтейнеры).

**Важно:** на сортировщик попадают **товары, а не ящики** (спецификация 6.1) — вскрытие ящиков обязательный процесс. Пустые ящики на сортировщик не подаются: они устанавливаются на этапе заполнения (скаты/накопители после сортировки), куда товары сбрасываются после сортировки (уточнение пользователя, запись 20 в отчёте о противоречиях).

### 2.2. Потоки ящиков (все четыре состояния, спецификация 6.2)

| Поток | Траектория |
|-------|------------|
| Пустые повторные ящики (80 %) | участок вскрытия (без повреждения) → сток пустых ящиков → этап заполнения (скаты/накопители после сортировки) |
| Новые ящики (20 %) | машина новых ящиков → сток пустых ящиков → этап заполнения (скаты/накопители после сортировки) |
| Заполненные ящики | этап заполнения (съём) → линия заклейки → сортировка по направлениям → паллеты → отгрузка |
| Бракованные ящики | удаление (сортировщик/сток) → компактор → вывоз |

**Способ транспортировки:** конвейер (вскрытие → сток → сортировщик → заклейка), конвейер/шуттл (заклейка → ячейки направлений), роботы-перевозчики/погрузчики (паллеты → буфер → ворота).

### 2.3. Потоки паллет (спецификация 6.3)

- Входные (185 паллет/ч — базовый сценарий ТЗ): ворота приёмки → буфер приёмки → разукрупнение; после съёма ящиков — порожние → накопитель пустых паллет → подача на паллетирование (повторное использование); излишек → возврат тары.
- Исходные: паллетирование (20 ящиков на паллету, смешение направлений допустимо; порожние паллеты из накопителя) → буфер отгрузки → ворота отгрузки → машина (16 паллет на машину).

**Способ транспортировки:** роботы-перевозчики/погрузчики между зонами.

### 2.4. Поток товаров nonsort (вспомогательный, спецификация 6.4)

**Траектория:** отбор на инфиде (форма/хрупкость/тип/штрихкод/негабарит > 320 мм) и/или из возвратных каналов → адресные ячейки (ручная сортировка по направлениям) → роллтейнер-станции (укладка в роллтейнеры) → 16 роллтейнеров на машину → отгрузка.

**Важно:** товары nonsort **проходят сортировку**, но ручную — операторы сортируют их по адресным ячейкам (ячейки направлений). Эталон производительности ручной сортировки — 250 товаров/ч на человека по 20 направлениям (ТЗ, спецификация 3.1 п. 19); потребность в операторах рассчитывается из доли nonsort (раздел 3.4).

**Способ транспортировки:** вручную (сортировка по адресным ячейкам), роботы-перевозчики (роллтейнеры к отгрузке).

### 2.5. Возвратный поток исключений (вспомогательный, спецификация 6.5)

**Траектория:** сортировщик/инфид → канал повторного прогона → повторная подача (скан). При повторном сбое → канал отбраковки → ручная обработка → возврат в основной поток либо перевод в nonsort.

**Причины:** нечитаемый код, множественное считывание, негабарит, повреждённая тара, отсутствие маршрута.

### 2.6. Прочие вспомогательные потоки (спецификация 6.6)

- Упавшие при сортировке товары → подъём → повторная подача в основной поток.
- Отходы (плёнка, ленты, скотч) → контейнеры отходов → вывоз.
- Роллтейнеры порожние → возврат от зоны отгрузки к участку nonsort.
- Транспортные движения роботов-перевозчиков/погрузчиков между всеми зонами.

## 3. Сверка с ТЗ: противоречия и неточности

1. **Терминология ТЗ.** «роллтейнер»/«ролл-кейдж», «ящик»/«короб»/«коробка», «палета»/«паллета» — разные термины для одного объекта; спецификация ввела единую терминологию (глоссарий). Термин «AGV» в ТЗ отсутствует — там «мобильные роботы-перевозчики»; AGV использовалось только в спецификации v1.0 и в проекте не применяется.
2. **Масса ящика vs масса товара.** ТЗ: ящик ≤ 30 кг, товар ≤ 10 кг, 27 товаров в ящике — полный ящик из максимальных товаров весил бы до 270 кг. Трактовка: 30 кг и 10 кг — максимальные пределы, средняя масса товара ≈ 1,1 кг; правило комплектования — число/масса/объём (спецификация 3.2).
3. **Размер товара vs объём ящика.** 320 мм — максимальная сторона; средний товар ≈ 150 мм (27 шт. в 96 л). Пара «предел + среднее» (спецификация 3.2).
4. **Вскрытие заклеенного ящика vs 80 % повторного использования.** Вскрытие должно выполняться без повреждения ящика (срез скотча) — требование к технологии, в ТЗ явно не сформулировано (спецификация 7.3).
5. **«Один ящик — одно направление» на выходе** при смешанном содержимом входящих ящиков требует пересортировки товаров — это требование процесса, не противоречие (спецификация 14.9).
6. **Непротиворечивые производные величины** (спецификация 14.9): 100 000/27 ≈ 3 700 ящиков/ч; 3 700/20 = 185 паллет/ч; 10 000/1 000 = 10 операторов на сортировщик.
7. **Пробелы (не противоречия):** размеры роллтейнеров, вместимость входной машины, время разгрузки, число приёмочных ворот, доля nonsort, доля исключений не заданы — будут определены на последующих этапах (спецификация 3.4).
