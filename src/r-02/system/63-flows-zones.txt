ФОРМАТ ОПИСАНИЯ ПОТОКА
============================================================
Строка потока:  [вход] - зона - выход1, выход2, ...

- Если перед первым символом "-" нет слова, то входящим
  словом для строки является первое слово из выхода
  предыдущей строки.
- Если перед символом "-" в строке есть слово, то оно
  является источником (одним из выходов предыдущей строки),
  т.к. выходов может быть несколько.
- Входом зоны всегда является выход предыдущей зоны.
  Для первой зоны потока вход — выход зоны исходного потока
  (или внешний источник).
- Единицы учёта: грузовики, паллеты, ящики (КТЯ), товары,
  роллтейнеры, брак ящиков, отходы.

ПОТОК 1. ОСНОВНОЙ ПОТОК ТОВАРОВ (100 000 товаров/ч, 3 700 ящиков/ч)
============================================================
- магистральный транспорт - входящие грузовики
- приемка - паллеты
- накопитель приемки - паллеты
- разукрупнение паллет - ящики, пустые паллеты
ящики - вскрытие ящиков - товары, пустые ящики
- подача на сортировку - товары
- сортировка товаров - ящики
- заклейка - ящики
- сортировка ящиков - ящики
- накопитель отгрузки - ящики
- паллетирование - паллеты
- отгрузка - паллеты
- магистральный транспорт - выходящие грузовики

Примечания:
- Сортировка товаров (спец. §7.6): установка пустых ящиков,
  контроль заполняемости (счёт, объём, масса <= 30 кг, плотность),
  утряска, съём заполненных ящиков.
- Ветвления зоны сортировки товаров: исключения -> Поток 7,
  выпавшие товары -> Поток 8, повреждённые ящики -> Поток 5.
- Ветвления зоны подачи на сортировку: товары nonsort -> Поток 6,
  товары-исключения -> Поток 7.

БАЛАНСЫ (проверка расчётом)
============================================================
- Товары: вход 100 000/ч = выход 100 000/ч (ящики + nonsort
  в роллтейнерах) — ТЗ.
- Ящики: 3 700/ч вход = 2 960/ч повторные (П3) + 740/ч новые
  (П4); брак до 740/ч (П5); установка на сортировку
  3 700/ч (П3+П4) — спец. §6.2, §11.2.
- Паллеты: входные 185/ч (П1) = пустые 185/ч (П2) =
  исходящие 185/ч (П1) — спец. §6.3.
- Роллтейнеры: до 12 машин/ч x 16 = 192/ч (П6) — спец. §3.3.
- Исходящие машины: 3 700 / 320 = 11,6 машин/ч (П1);
  входящие: 185 / 32 = 5,8 машин/ч (П1) — спец. §3.3.
- При доле nonsort d > 0 выходных ящиков меньше 3 700/ч
  (d = 10 % -> 3 333 ящиков/ч) — см. contradictions-report.md §5.3.
