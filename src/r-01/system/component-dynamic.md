# Динамические объекты системы

Основано на `src\specs\specification-r-01.md` (v2.0, новейшая). Сверено с `src\specs\Robozone Task 1.txt`.

Динамические объекты — сущности, которые порождаются, перемещаются по траекториям, накапливаются в буферах, преобразуются и покидают СЦ (раздел 4 спецификации). Статические компоненты (оборудование, персонал, накопители) см. в `component-static.md`.

---

## 1. Товары (в упаковках)

| Объект | Атрибуты | Траектория | Интенсивность |
|--------|----------|------------|---------------|
| **Товар** (штука в упаковке) | id, штрихкод, масса (≤ 10 кг), габарит/форма (коробка / цилиндр / конверт / мягкий пакет / округлая упаковка), хрупкость, тип содержимого, целевое направление, категория: «годен к АС» / «nonsort» / «исключение» | Приёмка → вскрытие ящиков → инфид (скан, вес/габариты) → сортировщик → ящик → отгрузка; категории «nonsort» и «исключение» — по боковым контурам | **Постоянный вход:** 100 000 товаров/ч; выход = входу |
| **Товар категории nonsort** | те же атрибуты + причина (форма / хрупкость / тип содержимого / штрихкод / негабарит > 320 мм) | инфид → адресные ячейки → роллтейнер → внешняя машина (16 роллтейнеров/машина) | **Вычисляется:** доля nonsort — параметр (ориентир 5–15 %) |
| **Товар-исключение** | те же атрибуты + причина (нечитаемый код / множественное считывание / негабарит / повреждённая тара / отсутствие маршрута) | инфид/сортировщик → канал повторного прогона → повторный скан; повторный сбой → канал отбраковки → ручная обработка → возврат в основной поток или перевод в nonsort | **Вычисляется:** доля исключений — параметр (ориентир 1–3 %) |
| **Выпавшие товары** | товар, выпавший при сортировке | подъём → повторная подача в основной поток | **Вычисляется:** параметр модели |

## 2. Ящики (КТЯ)

| Объект | Состояния | Траектория | Интенсивность |
|--------|-----------|------------|---------------|
| **Ящик (пустой повторный)** | новый / повторный / бракованный; пустой | вскрытие (без повреждения) → сток пустых ящиков → установка на сортировщик | **Постоянная:** 2 960 ящиков/ч (80 %) |
| **Ящик (новый)** | новый; пустой | машина новых ящиков → сток пустых ящиков → установка на сортировщик | **Вычисляется:** 740 ящиков/ч (20 % брака) |
| **Ящик (заполняемый)** | заполняемый | на сортировщике: сброс товаров, контроль заполняемости (счёт / объём / масса ≤ 30 кг), утряска | Постоянная |
| **Ящик (заполненный)** | заполненный → заклеенный | сортировщик (съём) → линия заклейки → маркировка → сортировка по направлениям → паллеты → буфер отгрузки → ворота | **Постоянная:** 3 700 ящиков/ч |
| **Ящик (бракованный)** | бракованный | удаление на сортировщике/в стоке → компактор → вывоз (внешняя машина) | **Вычисляется:** 740 ящиков/ч |

Баланс: 2 960 + 740 = 3 700 (вход = выход ящиков ✓).

## 3. Паллеты

| Объект | Атрибуты | Траектория | Интенсивность |
|--------|----------|------------|---------------|
| **Паллета входная (с ящиками)** | до 20 ящиков | ворота приёмки → буфер приёмки → депаллетайзер | **Постоянная:** 185 паллет/ч |
| **Паллета пустая** | пустая | после разукрупнения → накопитель пустых паллет → возврат (циркуляция тары) | **Постоянная:** 185 паллет/ч |
| **Паллета исходящая (с ящиками)** | до 20 ящиков; допускаются ящики **нескольких направлений** (малообъёмные) | паллетайзер → буфер отгрузки → ворота отгрузки → машина | **Постоянная:** 185 паллет/ч; на машину — 16 паллет |

## 4. Роллтейнеры

| Объект | Атрибуты | Траектория | Интенсивность |
|--------|----------|------------|---------------|
| **Роллтейнер (с товарами nonsort)** | состав — товары nonsort, целевая группа направлений / маршрут | участок nonsort (адресные ячейки) → укладка товаров → зона отгрузки → машина | **Вычисляется:** до 192/ч (12 машин/ч × 16) |
| **Роллтейнер порожний** | пустой | зона отгрузки → возврат к участку nonsort | **Вычисляется:** повторное использование |

## 5. Машины (грузовики)

| Объект | Атрибуты | Траектория | Интенсивность |
|--------|----------|------------|---------------|
| **Машина входящая** | план: 32 паллеты с ящиками | прибытие по графику магистрали → ворота приёмки → разгрузка → выезд | **Постоянная:** ≈5,8 машин/ч (185 ÷ 32; допущение о вместимости) |
| **Машина исходящая** | план: 32 паллеты = 16 ящиков (320) + 16 роллтейнеров; погрузка 2 ч | ворота отгрузки → погрузка волной по расписанию → событие «закрытие рейса» → выезд | **Вычисляется:** ≈11,6 машин/ч (3 700 ÷ 320); ёмкость ворот — 12 машин/ч (загрузка 96,4 %) |

## 6. Прочие динамические объекты

| Объект | Траектория | Интенсивность |
|--------|------------|---------------|
| **Отходы (стрейч-плёнка, ленты, скотч)** | участки разукрупнения/вскрытия → контейнеры отходов → вывоз | **Вычисляется:** из объёма обработки (параметр модели) |
| **Брак ящиков** | → компактор → вывоз (внешняя машина) | **Вычисляется:** 740 ящиков/ч (20 %) |
| **Информационные записи/события** | сопровождают каждый физический шаг: приёмка, сканирование, назначение маршрута, сброс в ячейку, заполнение ящика, съём, заклейка, исключение, паллетирование, загрузка машины, закрытие рейса — транслируются в WMS/TMS/трекинг | **Вычисляется:** по числу физических единиц |
