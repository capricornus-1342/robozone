# НАВЫК: Имитационная модель сортировочного центра (СЦ) на HTML+JS

## ЦЕЛЬ
Создать полноценную интерактивную имитационную модель сортировочного центра (СЦ) с балансировкой потоков, визуализацией и сбором статистики, работающую в браузере на HTML + JavaScript (используется Canvas/2D для визуализации). Модель должна отражать все ключевые компоненты, процессы, персонал и логику управления, описанные в спецификации. Результат — готовый к запуску HTML-файл (или набор файлов), который можно открыть в браузере.

## 1. ТРЕБОВАНИЯ К СИСТЕМЕ

### 1.1. Базовые сущности (классы)
Реализуйте следующие классы JavaScript:

- **`Truck`**: Представляет входящий или исходящий грузовик.
  - **Свойства**: `id`, `type` ('incoming'|'outgoing'), `load` (массив `Box`/`Pallet`/`Item`), `arrivalTime`, `scheduledTime`, `capacity`, `destRegion`.
  - **Методы**: `unload()`, `load(boxes)`, `depart()`.
- **`Pallet`**: Паллета с коробками.
  - **Свойства**: `id`, `weight`, `numBoxes`, `destRegions`.
  - **Метод**: `unpack()` - возвращает массив `Box`.
- **`Box`**: Коробка с товарами.
  - **Свойства**: `id`, `weight`, `destRegion`, `isOnPallet`.
- **`Item`**: Отдельный товар.
  - **Свойства**: `id`, `weight`, `destRegion`, `fragile`.
- **`ConveyorBelt`**: Конвейерная линия.
  - **Свойства**: `id`, `speed`, `buffer`, `maxBuffer`.
  - **Метод**: `process()`.
- **`Dock`**: Док разгрузки или погрузки.
  - **Свойства**: `id`, `type` ('unload'|'load'), `currentTruck`, `queue`.
  - **Метод**: `assignTruck(truck)`, `free()`.
- **`Pocket`**: Выходной карман сортировки.
  - **Свойства**: `id`, `region`, `capacity`, `boxes`, `threshold`.
  - **Метод**: `addBox(box)`, `isReadyToShip()`.
- **`Buffer`**: Промежуточный буфер.
  - **Свойства**: `id`, `maxCapacity`, `items`.
  - **Метод**: `add(item)`, `remove()`.
- **`Worker`**: Сотрудник СЦ.
  - **Свойства**: `id`, `role`, `speed` (индивидуальная производительность), `currentTask`.
  - **Методы**: `assignTask(task)`, `completeTask()`.
- **`SimulationEngine`**: Главный управляющий модуль.
  - **Свойства**: `time`, `speed`, `isRunning`, `eventQueue`.
  - **Методы**: `start()`, `pause()`, `step()`, `scheduleEvent(event, delay)`.
- **`StatisticsCollector`**: Сбор статистики.
  - **Методы**: `logEvent()`, `generateSummary()`, `saveToJSON()`, `saveToCSV()`.

### 1.3. Персонал (ключевые роли)
Предусмотрите в модели следующие роли сотрудников:

| Роль | Обозначение | Основные задачи | Ключевые параметры |
|---|---|---|---|
| Водитель (входящий) | `driver_in` | Пригоняет грузовик, ожидает, оформляет документы. | `arrivalTime`, `waitingTime` |
| Грузчик-приёмщик | `unloader` | Снимает коробки, кладёт на конвейер. | `speed` (коробок/час), `unloadType` |
| Оператор распаллетирования| `depalletizer` | Разбирает паллеты. | `speed` (коробок/час), `palletProcessingTime` |
| Сортировщик (ручной) | `sorter_manual`| Вручную ставит коробки в нужный карман. | `speed` (коробок/час) |
| Грузчик-отгрузчик | `loader` | Загружает коробки в исходящий грузовик. | `speed` (коробок/час) |
| Диспетчер | `dispatcher` | Координирует расписание, принимает решения. | `decisionTime` (мин) |

## 8. ПОЛНЫЙ ПРОЦЕСС ПО ЭТАПАм
**Этап 0: Прибытие и очередь**
- Грузовик прибывает, система назначает док или ставит в очередь.
**Этап 1: Разгрузка**
- **Коробки**: Автоматическая (2-5 сек/коробка) или ручная (10-15 сек/коробка) разгрузка на конвейер.
- **Паллеты**: Разгрузка (1-2 мин/паллета), транспортировка, распаллечивание (5-15 мин/паллета), подача коробок на конвейер.
- **Отдельные товары**: Выгрузка вручную, маркировка (10-20 сек/товар), подача на конвейер.
**Этап 2: Первичная обработка на конвейере**
- Сканирование, взвешивание, определение выхода (кармана) системой WMS, автоматическая сортировка.
**Этап 3: Накопление в карманах**
- Коробки накапливаются до достижения порога. При достижении порога WMS создает задание на отгрузку.
**Этап 4: Загрузка и отправка**
- Исходящий грузовик подъезжает, грузчики загружают коробки (в среднем 10 сек/коробка), оформляются документы, грузовик уезжает.

## 9. КЛЮЧЕВЫЕ УЗКИЕ МЕСТА
Обратите внимание на моделирование следующих "бутылочных горлышек":
- **Ручная разгрузка**: Ограничена производительностью грузчиков.
- **Распаллетирование**: Может стать узким местом при большом потоке паллет.
- **Карманы**: Их переполнение останавливает конвейер.
- **Загрузка исходящих грузовиков**: Медленный процесс, зависящий от числа грузчиков.

## 10. ПРИМЕР РЕАЛИЗАЦИИ (КОНЦЕПТУАЛЬНЫЙ)
```javascript
// simulation.js (фрагмент)
class SimulationEngine {
    constructor(config) {
        this.time = 0;
        this.speed = 1;
        this.isRunning = false;
        this.eventQueue = [];
        this.config = config;
        // Инициализация компонентов
        this.docks = [];
        this.conveyors = [];
        this.pockets = [];
        this.buffers = [];
        this.workers = []; // <--- Массив сотрудников
    }

    scheduleEvent(event, delay) {
        const eventTime = this.time + delay;
        this.eventQueue.push({ ...event, time: eventTime });
        this.eventQueue.sort((a, b) => a.time - b.time);
    }

    step() {
        if (this.eventQueue.length === 0) return false;
        const event = this.eventQueue.shift();
        this.time = event.time;
        this.processEvent(event);
        return true;
    }

    processEvent(event) {
        switch (event.type) {
            case 'ARRIVAL_TRUCK':
                this.handleArrival(event.truck);
                break;
            case 'UNLOAD_COMPLETE':
                this.handleUnloadComplete(event.truck);
                break;
            case 'PALLET_UNPACK_COMPLETE': // <--- Новое событие
                this.handlePalletUnpackComplete(event.pallet);
                break;
            case 'SORTING_STEP': // <--- Новое событие
                this.handleSortingStep(event.box);
                break;
            case 'POCKET_THRESHOLD_REACHED': // <--- Новое событие
                this.handlePocketThreshold(event.pocket);
                break;
            case 'SHIPMENT_LOAD_COMPLETE': // <--- Новое событие
                this.handleShipmentLoadComplete(event.truck);
                break;
            // ... другие события
        }
    }

    run() {
        // ...
    }
}
```
